# HomeQuest

Пробный Telegram-бот для семейного быта на базе **Donetick v0.1.86**, Go/GORM/SQLite.
Бот: [@Home_questbot](https://t.me/Home_questbot). Доступность временного Cloud-процесса
не гарантируется. `/start` → создать дом → выбрать IANA timezone → добавить задание.

Работают дома и приглашения, задания/фото/подтверждение/undo, повторы и напоминания,
баланс/вклад/XP/достижения, семейные награды, секретный wishlist, тестовый Premium.
Желания создаются пошагово с проверкой перед сохранением; свои желания можно
изменить или убрать. Тайная бронь при редактировании не раскрывается автору.
В «Настройки → Напоминания → Для всего дома» владелец выбирает интервалы;
тихие часы и отпуск остаются личными. Там же виден статус доставки в личный чат.
«Домашние планы» объединяют новые функции:
- готовые наборы для кухни, ванной и повседневных дел: правка, пропуск, подтверждение;
- свои комнаты и привязка заданий без удаления истории;
- очередь исполнителей после принятого выполнения и добровольная передача дела;
- недельный итог, настраиваемая цель со следующего понедельника, мягкое сообщение по понедельникам;
- общий список покупок: количество, заметки, «Куплю я», покупка, возврат в список;
  текст/голос создаёт черновик покупок с обязательным подтверждением.

Основной UI — компактные Telegram Widgets; ввод — обычные сообщения.
Сейчас Telegram запрещает Widgets обычным ботам даже в личных чатах
(`INPUT_MEDIA_WIDGET_NOT_ALLOWED`): [подтверждение в Bot API #947 от 13 ноября](https://github.com/tdlib/telegram-bot-api/issues/947).
Поэтому в текущем запуске TELEGRAM_UI=buttons: обычные сообщения с кнопками.

**AI подключён через VyceAI**: `https://vyceai.com/v1`, проверенный ID
`deepseek-4.1-flash-1017`. Реальные проверки JSON Schema, выполнения, отрицания,
будущего действия и черновика расписания прошли. Полная приёмка MVP ещё не
завершена: живой Telegram-клиент и человеческое русское голосовое ожидают проверки.
Локальный faster-whisper работает; синтетический STT smoke не подтвердил качество.

## Установка без Docker

HTML-стенд: `make preview` (в Cloud добавить `GO=/workspace/toolchains/go/bin/go`).
Открыть http://127.0.0.1:4173. Те же HTML-шаблоны, четыре вымышленных участника,
настоящие обработчики и отдельная временная SQLite; без токенов и отправки в Telegram.
Браузерный мост не считается проверкой совместимости: `make harness` отдельно
запускает официальный QuickJS/validator/renderer и browser E2E.

`TELEGRAM_UI=buttons` сразу отправляет обычные кнопки, без неудачных sendWidget.
После восстановления Widgets установить `TELEGRAM_UI=widgets` (или `auto`) и
перезапустить бот: тот же `widgets/family.html`, состояния и серверные действия.
При явном запрете API в этих режимах сохраняется безопасный fallback.


Go 1.24.3, Node 24, Python 3, npm, corepack, Git. В текущей Cloud-среде Go находится
в `/workspace/toolchains/go/bin/go`; можно передать `GO=...` в make.

```sh
make widgets build test
./scripts/setup-widget-harness.sh
make harness
```

Настройки: [.env.example](.env.example). Экспортируйте переменные в процесс;
автоматическая загрузка `.env` не выполняется. Секреты допускаются в JSON-файле
вне checkout с правами 0600; значения из окружения имеют приоритет.

```sh
python3 scripts/preflight.py /absolute/private/secrets.json
DATA_DIR=/absolute/private/data HOMEQUEST_SECRETS_FILE=/absolute/private/secrets.json BILLING_MODE=manual_test ./bin/homequest
curl -f http://127.0.0.1:2022/health
```

Отдельная миграция без сети/токена: `DATA_DIR=/absolute/private/data make migrate`.
Остановите бот перед ней; проверяется тот же flock.
Миграции GORM также запускаются синхронно при старте, SQLite `donetick.db` хранится в DATA_DIR.
Второй локальный consumer блокируется flock; webhook не удаляется; Telegram 409
останавливает polling. Нужны исходящие HTTPS-запросы, публичный endpoint не нужен.
`make dev` запускает исходный внутренний Donetick backend на 2021; семье он не нужен.
Не запускайте его как альтернативный публичный интерфейс без отдельного аудита.

## Агент с контекстом комнаты

`AI_MODE=agent` включает Eino и сохранение личного контекста. Откройте
«Домашние планы → Комнаты → Дела комнаты», затем отправьте текст или голос:
«Перенеси все дела здесь на завтра в 19:00». Бот покажет общий план; подтвердите
кнопкой или ответом «Подтверждаю». Повторное подтверждение не повторяет изменения.
`/agent` показывает выбранный дом/комнату, `/stop` останавливает текущую просьбу.
Контекст и последние 4 обращения сохраняются при restart; очищаются после суток
без обращений, при смене дома или кнопкой «Сбросить контекст».

Первый этап покрывает управление заданиями, создание комнат и добавление покупок.
Награды, wishlist, Premium и остальные функции пока доступны обычными кнопками,
но ещё не инструментами агента. Все изменения агента сейчас требуют общего preview;
обязательные фото и подтверждение другого участника сохраняются. `AI_MODE=legacy`
возвращает прежний ограниченный помощник. [Текущий охват](docs/STATUS.md).

## Локальное распознавание речи

```sh
python3 -m venv /absolute/private/stt-venv
/absolute/private/stt-venv/bin/pip install -r requirements-stt.lock
STT_MODEL_DIR=/absolute/private/stt-models /absolute/private/stt-venv/bin/python scripts/setup-stt.py
```

В окружении бота задайте STT_PYTHON, STT_MODEL_DIR и STT_MODEL=small.
CPU int8, 2 потока, одна обработка одновременно, до 60 секунд/4 МБ.
Для совместимости сохранён один набор настроек NICKLLM_BASE_URL/API_KEY/MODEL;
он теперь указывает на разрешённый владельцем VyceAI. Другой модели в fallback нет.
Аудио временное; текст AI-очереди удаляется после обработки или через 15 минут.
