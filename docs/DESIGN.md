# Карточки HomeQuest

Нативная тема Telegram, Open Props 1.7.23 (size-2/3, radius-3), Lucide Static 1.73.0
(8 отдельных SVG). LICENSE в docs/licenses. build-widgets.mjs извлекает токены при сборке;
в сообщении нет CDN, React, внешних шрифтов, CSS imports или запросов в сеть.

`widgets/family.html` — единый продуктовый шаблон: заголовок, текст, список действий.
Панель использует --tg-theme-bg-color/text-color; шрифт системный; кнопки ≥44px.
Пользовательские строки вставляются через textContent. Фото приходят отдельным
Telegram media message. Public_data не используется, состояние — проекция для viewer.

Ограничения проверяются в Go и сборке: HTML 32768, zlib9 4096 (цель 3500), state
1024, request 64 байта. Пагинация заданий/подарков/наград — одна позиция на карточку.
В списках длинные названия сокращаются; подробности подарка доступны отдельно.

Официальный QuickJS + validator + renderer: E02 на 200/320/390px, light/dark/custom;
дополнительно 32 граничные продуктовые карточки на 200px, высота ≤600px. Скриншоты из того же
renderer: [light](screenshots/home-light.png), [dark](screenshots/home-dark.png),
[custom](screenshots/home-custom.png). Проверка выявила и исправила прозрачный фон
панели на белом тестовом canvas тёмной темы. Это не скриншоты Telegram-клиента.

Источник шаблона: widgets/src/card.css и card.js, сборка в family.html.
Использованы 8 отдельных Lucide SVG: house, circle-check, gift, trophy,
calendar-days, mic, users, settings. Кнопки: главное действие во всю ширину,
дополнительные — сетка из двух колонок, на 200px одна колонка. Все ≥44px. На узком экране до 3 действий; при длинном
заголовке 1–2. Длинный текст тоже разбивается на страницы. «Далее»/«Ещё действия»
переключает локальную страницу, не вызывает backend. Длинный заголовок сохраняется
полностью; декоративная строка бренда уступает ему место.
Цвета продуктовой карточки только Telegram palette; preview предлагает шалфейную тему.
Open Props size-2/3 и radius-3 подставляются в CSS на этапе сборки.
Шаблон меньше целевого бюджета 3500 байт zlib9. Полный пакет/sprite не встраивается.

preview/ — отдельная оболочка разработчика, не Mini App. iframe получает точно
тот же HTML; только снаружи добавляется browser bridge к локальному bot-probe.
Страницы не содержат реальных семей/ключей, сервер слушает только loopback.
Browser E2E проверяет семейные пути, фото/approval/undo, награды, wishlist, Premium, комнаты/наборы/очередь, недельный итог и покупки.
ACK без state update, RATE_LIMITED/TIMEOUT/FAILED проверены в официальном runtime.
Все различные проекции подробных HTML-сценариев дополнительно проверяются официальным renderer; живой клиент остаётся отдельной приёмкой.

Текущая сборка: 9010 байт UTF-8; 3072 байт Python zlib9
(3127 байт Node zlib9); оба ниже целевого бюджета 3500.

Подарки: один шаг на поле, «Пропустить»/«Оставить», «Назад»/«Отмена», отдельная
проверка перед сохранением и подтверждение архивирования. Черновики сохраняются
в БД; состояние карточки содержит только короткую проекцию. Секретность брони
обеспечивается серверной сериализацией, не скрытием CSS. Семейные напоминания
используют тот же шаблон, токены и навигацию; новых визуальных зависимостей нет.


Новые разделы входят через одну кнопку «Домашние планы», чтобы домашняя карточка
не переполнялась. Редактирование и опасные действия вынесены в «Параметры».
Набор, очередь и покупки сохраняют черновик на сервере; карточка содержит только
текущий шаг. На каждом шаге есть выход, пагинация короткая. Бронь покупки открыта
семье; тайная бронь подарка остаётся отдельной моделью с приватной сериализацией.
