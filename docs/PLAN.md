# HomeQuest: план продолжения

Продукт: личные Telegram Widgets для взрослых участников независимых семей.
База: Donetick v0.1.86, Go, GORM/SQLite; отдельный сайт семье не нужен.

Новая доменная логика: сначала падающий тест, затем реализация.
Не смешивать runtime/harness, контролируемый transport и live Telegram.
Точные требования владельца остаются в исходном диалоге; секретный промпт не копируется.

Полный аудит реализации и незакрытых критериев по каждому T ID — [STATUS](STATUS.md).
«Вертикальный сценарий работает» не означает полную приёмку задачи.


## Согласованное расширение после аудита E2E

| Пункт | Результат | Проверка |
|---|---|---|
| 1 | Наборы с редактированием/пропуском и комнаты | plans-e2e + rooms/atomic import integration |
| 2 | Чередование и добровольная передача | plans-e2e + rotation/undo/departure/expiry/reviewer conflict |
| 3 | Недельный итог и цель | plans-e2e + snapshots/timezone/worker restart |
| 4 | Общий список покупок, текст/голос → черновик | shopping-e2e + claim race/audit/scope + live LLM eval |
| 5–6 | Исключены владельцем | Не реализуются в этом изменении |

Все перечисленные пути используют общие продуктовые обработчики и SQLite.
Остаток внешней приёмки: человеческий Telegram voice, разрешение Widgets платформой,
доступ к серверу и GitHub Actions secrets для server deployment. Это не блокирует HTML E2E.

## Агент после MVP

Первый вертикальный этап реализован: Eino, сохраняемый контекст комнаты,
типизированные 30 изменений, preview/apply, голосовое подтверждение и HTML E2E.
Второй этап: существующие покупки, каталог/заявки наград и полное создание задания
с исполнителем, фото, подтверждением и проверяющим; scoped reads и snapshot guard.
Добавлено чтение баланса/вклада/XP/рейтинга без новых источников учёта.
Продолжение без повторного выбора архитектуры: расширить Catalog существующими
доменными действиями wishlist/достижений/участников/настроек/отчётов, добавляя
проекции с правами, снимки версий и тесты. Затем reply-контекст и полный UI parity
gate; внешний MCP отдельно. Текущий перечень ограничений — STATUS.
