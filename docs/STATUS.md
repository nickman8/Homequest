## Голосовой агент: первый работающий этап

Eino v0.9.23 подключён к существующим доменным сервисам и той же SQLite.
`AI_MODE=agent` включает 15 типов изменений: создание/редактирование/срок/
повторение/назначение/комната/описание/правила/очередь/пауза/возобновление/отмена/
выполнение задания, создание комнаты, добавление покупок. Чтение задач и явная
смена личной комнаты доступны инструментами. `AI_MODE=legacy` сохраняет прежний
парсер. Подробности архитектуры: [AGENT_RESEARCH.md](AGENT_RESEARCH.md).

Контекст дома/комнаты, ссылки на последние задачи и до 4 пар реплик сохраняются
после restart. Сброс после 24 часов без обращений, смены дома или ручного действия.
Новое согласие отдельно объясняет передачу контекста провайдеру. Все изменения
этой версии проходят общий preview; голосовое/текстовое подтверждение привязано
к конкретному плану. Нет подтверждения каждого внутреннего вызова инструмента.
План живёт 15 минут, пачка атомарна, stale версии/права/комната запрещают применение.
`/agent` и «Домашние планы → Помощник» показывают контекст; `/stop` останавливает запрос.

Проверено: новый HTML E2E (67 состояний), Eino с детерминированной моделью и SQLite,
реальный Eino/VyceAI → выбор кухни → перенос → preview/apply на вымышленной семье.
Человеческий голос и пользовательский Telegram-клиент остаются отдельной live-приёмкой.
Поздняя повторная проверка VyceAI: два таймаута агентного запроса (25.17/25.14 s);
минимальный completion тоже не получил ответ за 25 s (curl 28/status 000).
Первый live agent smoke прошёл, но текущая доступность completion не подтверждена.
Это внешний блокер повторной живой приёмки, не подтверждение ошибки ключа.

Cloud-процесс новой сборки запущен: PID 293683, session 11906; DB/scheduler ready,
Telegram polling, UI buttons, AI_MODE=agent. Это статус на момент проверки;
доступность после завершения среды не гарантирована. Команда рестарта — RUNBOOK.

Это ещё не полный охват приложения агентом. Дальше: награды/wishlist/статистика,

## Перенос на сервер LiteLLM и автодеплой

Запрошен владельцем после HTML-этапа. SSH повторно не достигает авторизации:
ECONNREFUSED, managed TCP disabled/VPN отсутствует. Сервер не изменялся, безопасность
соседства с LiteLLM не подтверждена, текущий Cloud consumer не остановлен.
Подготовлены read-only аудит, изолированный systemd unit, проверяемый архив релиза,
activator с backup/миграцией/health и корректным отказом от потери новых фактов при
неудачном старте, GitHub deploy job после checks. Job выключен до server audit и
настройки отдельного deployment key. Нельзя считать эту подготовку выполненным
серверным запуском. Точный порядок и единственный сетевой блокер — RUNBOOK.

Дополнительный блокер настройки CI: текущий GitHub CLI integration token не имеет
Actions variables/Secrets public-key access (HTTP 403); connector разрешает код/PR, но не предоставляет
методов управления Actions secrets/variables. Job явно выключен false guard,
секреты сервера в GitHub не передавались.
