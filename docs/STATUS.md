# Состояние HomeQuest на 18 ноября 2026

Бот для пробного использования — [@Home_questbot](https://t.me/Home_questbot).
Путь с телефона — `/start` → создать дом → указать часовой пояс → добавить дело → отметить выполнение.
В Telegram доступны кнопки. В браузерном стенде можно пройти те же действия на HTML-карточках.
Платежи отключены. Тестовый семейный Premium включает расширенную статистику и повышенный лимит помощника.

на 200 px плюс 24 варианта темы/ширины. Резервная копия и команда рестарта в [RUNBOOK.md](RUNBOOK.md).

## Реализация и проверки

В каталоге Eino 67 типов изменений. Разделы приложения, права и уровни проверки перечислены в
[матрице](TEST_MATRIX.md). Помощник читает актуальные данные выбранного дома и комнаты.
Пользователь видит общий план, включая цену награды, расписание и зависимые действия,
до записи в семейную базу. Ответ на карточку привязан к разрешённому объекту и его состоянию.
Человек прикладывает фото в личном чате. Для вступления он открывает приглашение сам.
Отдельный публичный MCP-сервер семейному боту для этих функций не требуется.

Три исправления подтверждены регрессиями: в день перевода часов сохраняется выбранное местное
время будущих повторов, после исключения участника браузерный стенд скрывает старую карточку,
а ответ на список из нескольких объектов больше не выбирает первый по порядку.
Старое расписание с уже записанным неверным часом можно исправить редактированием;
исходный выбор человека в таких старых записях восстановить автоматически невозможно.

## Что ещё требует внешней проверки

- **Telegram Widgets.** Обе реальные отправки, включая минимальную карточку, получили `INPUT_MEDIA_WIDGET_NOT_ALLOWED`.
  В ответе от 17 ноября по UTC сопровождающий Bot API подтвердил, что Premium не открывает доступ. Публичную дату включения
  обнаружить не удалось. Когда доступ выдадут, выбрать `TELEGRAM_UI=widgets`, перезапустить единственный
  consumer и нажать действие в личном чате. [Ответ Telegram](https://github.com/tdlib/telegram-bot-api/issues/947#issuecomment-6958037721)
- **Человек и личный чат.** Автоматически подтверждены локальное русское STT, реальная модель и начисление на тестовой SQLite.
  Для приёмки на телефоне создать дело «Вынести мусор», отправить голосовое «Я выкинул мусор» и проверить предложенное действие и баланс.
  Для проверки второго участника пригласить его из меню дома.
- **Сервер LiteLLM.** 18 ноября подключение на TCP/22 снова отклонено до авторизации. Аудит ресурсов на сервере
  и переключение polling ждут доступного SSH-маршрута. Интеграция GitHub вернула 403 на secrets/variables.
  После подготовки доступа следовать runbook: read-only аудит, проверка ресурсов, deploy key с отдельным пользователем,
  включение защищённого workflow. Cloud-процесс зависит от жизни среды. [Инструкция](RUNBOOK.md)
